# Phishing URL Detection & Investigation

## Project Overview

This project demonstrates a basic cybersecurity investigation
focused on identifying potential phishing indicators in URLs.

The investigation was conducted using Windows-based tools and
VirusTotal.

## Objectives

- Perform DNS investigation using PowerShell
- Analyse URL characteristics
- Identify potential phishing indicators
- Document Indicators of Compromise (IOCs)
- Assess security risk
- Produce a structured investigation report

## Tools Used

- Windows PowerShell
- nslookup
- Web Browser
- VirusTotal

## Investigation Process

1. Performed DNS lookup on the domain using PowerShell.
2. Recorded the associated IP address.
3. Analysed the URL for suspicious characteristics.
4. Checked the URL using VirusTotal.
5. Documented findings and indicators.
6. Assigned a risk level based on the investigation.
7. Created an investigation report and evidence log.

## Findings

The test URL did not show obvious indicators of phishing or
malicious activity during the investigation.

The investigation demonstrated how DNS information, URL
characteristics and multiple security detections can be used
together when assessing a suspicious URL.
